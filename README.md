# AI Report Summary Project
 
## Overview
Python 기반 Excel(AER Report) 자동 분석 및 Summary Sheet 생성 프로젝트입니다.
 
## Features
- Summary Sheet 자동 생성
- 테스트 진행률 계산
- Waveform 분석
- Missing Image 검출
- Daily Progress 생성
- Logging
- Excel Style 유지
